    $_.IPAddress -and

} | ForEach-Object {
    Write-Host "Vite局域网地址：http://$($_.IPAddress):5173"
}

Docker 部署侧的备份与上线护栏（指南 §10.1 / §6.3）
scripts/backup.sh --install-cron   每天 03:30 备库（mysqldump --single-transaction 不锁表）；清理+异地都在脚本里
  保留天数读 .env 的 BACKUP_KEEP_DAYS（默认 14）、异地目标读 BACKUP_SYNC_DIR（NAS 目录或 user@host:/path 走 rsync）
  ★ 备份只落同一块盘等于没备份；cron 装在【部署机】（靠 docker compose exec mysql），日志 logs/backup-cron.log
scripts/guard-sql-init.sh   建完库跑一次上护栏：把 sql-init 建库脚本挪进 sql-init.disabled/ + 落 .disabled 标记
  让「卷被重建时静默清库」失效（重跑 bootstrap 也不会被撤销）；--status 看状态 / --unlock 解锁 / --comment-compose 再注释那行挂载
  ★ 锁是本机状态不随仓库走，新机部署天然无锁、能正常建库

PR冲突解决方法
# 路 1：把 PR 分支拉到本地解，回推 fork → PR 自己变「可合并」，保留作者署名
gh pr checkout 1            # 自动建本地分支 + 加 fork 远端（#1 开了 maintainerCanModify，你有权推）
git merge origin/main       # 解冲突 → 改文件 → git add → git commit
git push <fork远端名> HEAD:main
# 路 2：直接在 main 上吃掉它（你刚才做的）
git fetch origin pull/1/head:pr-1
git checkout main; git merge pr-1    # 解冲突、add、commit
git push origin main                 # GitHub 会把 PR #1 自动标为 Merged
