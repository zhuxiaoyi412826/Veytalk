# 更新日志 CHANGELOG

本文件记录 **IM 即时通讯系统** 的所有重要变更（代码、配置、文档均含）。

**约定（务必遵守）**：

- 从现在起，**本项目每一次更新都要在本文件里留一条描述**，无论改动大小。
- 采用 [Keep a Changelog](https://keepachangelog.com/zh-CN/) 风格，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。
- 变更按类型分组：`新增 Added` / `变更 Changed` / `修复 Fixed` / `移除 Removed` / `废弃 Deprecated` / `安全 Security`。
- 每条写清「改了什么、为什么、涉及文件」三要素，**一条不超 3 行**；验证过程、取证数字、「本轮零代码」这类自证句子一律不进本文件（口径见 [`md/项目长期遵守规范.md`](./项目长期遵守规范.md) 6.6）。
  例外：DDL 与要用户执行的 SQL、「不重启 / 不重新打包就不生效」这类操作性提醒必须留。
- 一个版本区内 `### 新增 Added` / `### 变更 Changed` / `### 修复 Fixed` **各只出现一次**，新条目插到既有分组顶部。
- **最新的版本放在最上面**；未发布的改动先归到顶部的 `未发布 Unreleased` 区。

### 安全 Security

- **★ Dependabot PR 降噪（采用 A+B：止镜像浪费 + 分批开 PR）**。`build-and-package.yml` 给 `docker-image`、`mirror-images` 两 job 加 `if: github.actor != 'dependabot[bot]' || github.event_name != 'pull_request'`——只为 dependabot 发起的 PR 跳过打镜像（依赖 bump 只要 `build-jar`/`build-web` 编译过即证明未破坏构建，不必为每个 bump 重打镜像）；main/tag（含该 PR 合并后）照常构建推送，不影响正式产物。`dependabot.yml` 三生态 `open-pull-requests-limit` 由 10 调 5，分批来避免刷屏。（C——dependabot PR 整条不跑 build-and-package——与 A 互斥，会放弃“验证 bump 能否编译”，未采用）。涉及：`.github/workflows/build-and-package.yml`、`.github/dependabot.yml`。

- **★ CI 扫描节奏降噪（用户要求：Dependabot 改每月一次、漏洞扫描改每月最后一个周日）**。`dependabot.yml` 三生态 `interval` 由 `weekly` 改 `monthly`（Dependabot monthly 固定当月 1 号跑，天然从下月起算）。`security.yml` 定时由「每周一」改为「每周日触发 + 新增 `gate` job 判定本月最后一个周日才放行」（GitHub cron 无「最后一个周日」原生写法，day-of-month 与 day-of-week 同限是「或」关系会多触发，故用 gate 精确判定；非最后一个周日的周日只跑几秒 gate、两个扫描 job 短路跳过）；gate 内置 cutoff `20261201` 跳过本月 11/29，**首次真扫 = 12/27**；PR/push main/手动不受 gate 限制照常扫。★ CodeQL 定时仍为每周（属 SAST 非依赖漏洞扫描，未纳入本次调整，如需一并改月再说）。涉及：`.github/dependabot.yml`、`.github/workflows/security.yml`。

- **★ CI/CD 安全与质量闸门加固（用户选定实现「跑测试 / SCA / SHA 固定 / SBOM」四项）**。`build-and-package.yml`：所有 `uses:` 由浮动标签改**固定到 commit SHA**（供应链防 Action 被劫持），新增 `test` job 跑 `mvn test` 作 PR 编译/测试门（★ 当前 Maven 模块暂无 JUnit 单测，补上即自动纳入），build-jar 追加 CycloneDX 聚合 SBOM 并上传 artifact。新增三份独立配置：`security.yml`（npm audit + OWASP dependency-check，口径 **PR 只报告 / main·定时 high·critical 阻断**）、`codeql.yml`（Java + JS/TS SAST）、`dependabot.yml`（actions/maven/npm 每周升级 PR）。★ 可选配 `NVD_API_KEY` secret（不配则 dependency-check 走匿名拉取、runner 共享 IP 易被限流）；CodeQL 默认不阻断合入（先建基线，要变硬门去分支保护勾选该 check）。涉及：`.github/workflows/{build-and-package,security,codeql}.yml`、`.github/dependabot.yml`（4 份 YAML 均过 safe_load 校验）。
