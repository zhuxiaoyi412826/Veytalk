4. 日志留存不够法定期限
Docker部署指南 §11.4 那张表：error.log 留 60 天，其余六档（含 SQL/、MODERATION/）30 天。
《网络安全法》第 21 条要求网络日志留存不少于六个月。要么把六档 maxHistory 拉到 180 天并配磁盘配额，要么单独给「合规留存档」做冷存储（OSS/S3）+ 归档不可篡改。
这条是能改代码就改完的，成本最低、风险最高，建议先做。

七、工程与安全补充（本轮通读代码后新增，前文未覆盖，按「低成本高风险」排序）

1. 没有版本化数据库迁移框架：现状是手写 sql/migration_*.sql + 人肉 mysql source 导入 + 人肉清 im:auth:perm 缓存。缺 Flyway / Liquibase 这类「带版本号、启动按序自动应用、可校验可回滚」的机制；生产改表漏跑一步或跑错顺序 = 数据错乱且无痕。前文只谈了备份/主从，没谈 schema 演进。
2. 没有优雅停机（graceful shutdown）：全仓无 server.shutdown=graceful（application.yml 里的 shutdown-timeout:200ms 是 Redis Lettuce 连接池的，不是它）。叠加大量内存态（远控 ticket/aesKey 的 ConcurrentHashMap、在线状态、通话信令、正在 PUT 的分片），任何重启/部署 = 正在通话/远控/上传瞬间裸断且不可恢复。这与「单实例改造」是两件事，单实例也该先把计划内重启的体面收口做了。
3. 传输层安全头只做了一半：SecurityHeaderConfig 有 nosniff / X-Frame-Options:DENY / Referrer-Policy，但没有 Content-Security-Policy；nginx ssl.conf 的 Strict-Transport-Security（HSTS）是注释掉的。交友+支付类站点 XSS 与降级攻击面，CSP 是第一道闸。前文安全全在风控/反诈/审核，无一条讲 HTTP 响应头。
4. 没有依赖 CVE 自动扫描与升级（SCA）：无 .github/dependabot.yml。前文只处理了许可证（GPL/ffmpeg），没处理已知漏洞。Spring/Jackson/netty/ffmpeg/MinIO SDK 任一爆 CVE 都收不到提醒。补：Dependabot（依赖+Actions）+ 镜像 trivy/grype + 前端 npm audit/OSV-Scanner 接进现有 CI。
5. 监控有端点和文档，缺告警规则与值班闭环：actuator/prometheus 已暴露（health/info/prometheus/metrics，仅 127.0.0.1:8081），有 md/监控告警部署指南.md，但没有任何 alert 规则。证书到期现在靠手册「每月人工 openssl -enddate 巡检」一定会忘；消息积压、WS 在线数异常、大模型花费超阈、TURN 用量、磁盘水位、5xx/失败率都无人值守。补一组 alertmanager 规则 + 推 IM/短信的值班通道。
6. API 无版本化：/api/* 裸奔无 /v1。现有 Web/Electron/原生安卓/(iOS 规划)四类客户端共用同一路径；原生 App 装了就不能强制升级，接口字段语义一改旧 App 直接打挂。新接口纳入 /api/v1 或加版本协商 + 弃用窗口。
7. WebSocket 握手疑似用 query 携带 token（?token=）：token 进 URL 会落 nginx access_log、代理与浏览器历史，是泄露面。改首帧鉴权或 Sec-WebSocket-Protocol / Cookie。（此条待核实当前握手实现。）
