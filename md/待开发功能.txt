1. 视频上传与多清晰度转码模块
- Web端上传视频**前端不压缩**，原始视频上传到服务端，服务端做转码，输出多种清晰度版本。
- 客户端下载视频时，可选择不同清晰度拉取。
- 客户端（非web）：客户端侧已经实现视频压缩。
- 转码任务状态：排队 / 转码中 / 成功 / 失败，支持**重试机制**，失败原因记录（源文件损坏、超时、资源不足）。
- 转码资源隔离：防止大视频耗尽服务器 CPU，限制并发转码数、任务优先级。
- 视频权限：不同清晰度文件**权限控制**，和原视频权限保持一致，不能绕过权限直接访问转码分片。
2. 账号认证体系
- 登录方式：账号密码登录、邮箱登录、手机验证码登录。
- 安全组件：腾讯防水墙（人机验证）。
- 密码找回：邮箱找回、手机验证码找回。
- 登录设备管理：查看登录设备、踢下线；支持单点登录/多端互踢。
- 登录日志：记录每次登录信息。
- 验证码策略：频率限制（防短信 / 邮箱轰炸）、验证码有效期、验证码复用禁止。
- 密码策略：密码复杂度配置、密码历史记录，禁止重复使用旧密码。
- 敏感操作二次验证：修改密码、解绑邮箱 / 手机、踢设备下线，需要二次验证码 / 人机验证。
- Token 设计：区分**access_token（短期）+ refresh_token（长期）**；refresh_token 在踢下线时一并失效。
- 单点登录细节：同一账号可配置两种模式：①多端互踢（只允许 1 端在线）②允许多端在线（仅支持单独踢指定设备）。
- 登录日志字段：IP、设备 UA、地理位置、登录结果（成功 / 失败）、操作时间、登录类型。
3. 远程电脑控制功能
- 权限模型：被控端授权机制，**必须被控方同意才能发起远程**；可设置只读 / 可操作权限。
- 流压缩：屏幕画面编码压缩，带宽自适应调节；键鼠事件可靠传输。
- 安全鉴权：远程会话独立 token，一次性有效；会话超时自动断开。
- 会话审计：远程会话日志，记录开始 / 结束时间、操作双方；可选录屏审计。
- NAT 穿透 fallback：P2P 优先，P2P 不通走服务端中继；中继带宽限流。
- 被控端状态：离线、忙、拒绝接入。
4. 关键词过滤模块
- 固定关键词屏蔽 + 动态关键词屏蔽（后台可新增关键词，无需发版）。

5. 文件预览模块
- 支持主流文件类型在线预览。
- 文件预览白名单配置，仅白名单后缀允许预览。
- 预览安全：预览服务沙箱隔离，禁止预览文件执行脚本；预览**不提供原始文件下载权限**（预览水印可选）。
- 预览转换：office/pdf 等文档后端转图片 /pdf 预览；大文件预览限制大小上限。
- 白名单反向黑名单：白名单后缀列表，不在白名单直接拒绝预览；MIME 类型双重校验，防止改后缀绕过。
- 水印：可选全局预览水印（账号信息），防截图泄露。

6. IM即时通讯模块
- 好友列表未读红点、聊天窗口红点。
- 单聊、群聊消息已读标记。
- 黑名单：屏蔽指定用户消息，不再接收对方消息。
- 消息类型：文本、图片、文件、视频、语音；关键词过滤**所有消息类型**（不止文本）。
- 消息时序：服务端生成全局 msgId，解决客户端本地时间错乱导致消息排序混乱。
- 消息撤回 / 删除：单聊 / 群聊消息撤回；本地 DB 同步删除 / 标记删除；区分「仅本地删除」和「服务端删除」。
- 离线消息：用户离线期间消息持久化，上线拉取增量消息；消息过期清理策略。
- 已读边界：群聊已读，只记录成员已读点位，**不存储每一条消息的已读记录**（防止表爆炸）；区分：消息送达、消息已读两个状态。
- 黑名单补充：黑名单双向控制（A 拉黑 B，B 不能发消息给 A；A 也收不到 B 消息）；黑名单列表服务端存储，多端同步黑名单。

7. 本地消息缓存方案（浏览器端）
- 缓存一致性：本地缓存文件 / 视频，服务端文件更新后，缓存失效策略（ETag / 版本号）。
- 缓存开关：用户可手动清除消息缓存、文件视频缓存。
- 红点：区分「总未读」「会话未读」；已读同步多端，A 端标记已读，其他端红点消失。
- 使用SQLite：每个用户独立本地DB文件，浏览器刷新页面消息历史不丢失。
- 浏览器本地存储辅助；文件、视频本地缓存，减少重复网络请求。
本地 SQLite（浏览器 WASM SQLite）重点坑：
- 浏览器存储配额限制（Origin 配额，一般几十 MB），消息 / 缓存超限策略：LRU 淘汰旧消息、旧视频缓存。
- DB 迁移：版本升级时本地 SQLite schema 变更，需要迁移脚本，避免刷新页面 DB 损坏。
- 多标签页冲突：同一浏览器打开多个 Tab，多 Tab 读写同一个用户本地 DB，锁冲突处理。
- 数据备份：本地消息仅浏览器缓存，清除浏览器数据后丢失，提示用户；可支持手动导出消息。
- 缓存隔离：消息 DB、文件视频缓存分开；视频缓存可单独设置最大占用空间，LRU 自动清理。
8. 安全防护功能
1. XSS/CSRF 防护：聊天消息渲染转义，防止 XSS；接口 CSRF Token。
2. 接口鉴权：所有 API 统一鉴权，防止越权访问别人视频、消息、文件。
3. 限流：登录接口、上传接口、消息发送接口、远程控制接口，全接口限流防刷

## 技术约束与隐性需求
1. SQLite在浏览器：WebSQL / WASM版SQLite，每个用户单独db文件，注意浏览器存储配额、持久化权限。
2. 视频转码：服务端转码任务队列，转码耗时长，不能同步阻塞上传接口；需要任务状态回调、进度查询。原始文件存储 + 多清晰度分片文件存储。
3. 多端互踢：token机制，服务端维护在线设备session；踢下线后客户端token失效，前端感知并跳转登录。
4. 消息已读：单聊/群聊已读状态，群聊需要记录每个人的已读点位；消息有序性。
5. 关键词动态屏蔽：热更新词库，不需要重启服务；支持正则/普通关键词；需要区分消息发送前拦截、日志审计。
6. 文件预览白名单：后端校验后缀，防止恶意文件预览；预览服务隔离，安全沙箱。
7. 腾讯防水墙：登录、找回密码、敏感操作接入人机验证，防刷。
8. 远程桌面控制：网络穿透、流传输、权限控制、安全鉴权。
9. 本地缓存边界：浏览器本地存储有容量上限；清理缓存策略；离线消息；本地DB和服务端消息同步机制。
10. 黑名单：消息投递层拦截，不推送黑名单用户消息，不只是前端隐藏。
